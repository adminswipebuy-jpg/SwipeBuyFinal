# SwipeBuy V5.6 — AI Assistant + Universal Discovery

V5.6 introduces **Ask SwipeBuy**, the first cross-platform assistant/search layer. Users can describe what they need in natural language and SwipeBuy routes the request toward products, jobs, property, sports, finance, education, services and travel data available in Firestore.

This release is an assistant/discovery foundation. It is intentionally not presented as a full general-purpose AI model. A production rollout should connect a trusted backend model gateway with authenticated tools and permissions.

The prior V5.5 smart-alert and personalization systems remain included.
