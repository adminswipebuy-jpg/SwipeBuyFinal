# SwipeBuy V6.9 — Full Editing Timeline

Adds a timeline editing foundation on top of V6.8:

- Multi-clip timeline UI with reorder support
- Clip splitting and per-clip trim ranges
- Undo history foundation
- Original/music volume lanes
- Audio track selection
- Caption timing/accessibility toggle
- Preview of selected timeline clip
- Editor handoff from the advanced editor

This release stores edit decisions; server-side media rendering/transcoding is still a production integration task.
