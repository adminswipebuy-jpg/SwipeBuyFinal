# SwipeBuy V4.2 — Creator + Media + Social Engine

This release moves the content ecosystem toward real social participation.

## Added
- Creator post composer for text, photo and video.
- Firebase Storage uploads for creator media.
- Published creator content written to `content_items`.
- Follow/unfollow for content creators.
- Like/unlike for content posts.
- Comments backed by `content_comments`.
- Comment bottom sheet UI.
- Real image media rendering in the vertical feed.
- Firestore and Storage rules for content and creator media.

## Next target
V4.3 should add a production media player, short-video editing, creator profiles, share links, view/watch-time events, moderation queues, and server-side feed ranking.
