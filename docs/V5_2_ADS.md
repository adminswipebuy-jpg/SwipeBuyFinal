# SwipeBuy V5.2 — Advertising Infrastructure

Adds the Google Mobile Ads Flutter plugin, centralized ad configuration, test banner/interstitial slots, and an in-app advertising page.

## Production checklist
- Replace Google test app/ad unit IDs with your own AdMob IDs.
- Configure consent/privacy flows appropriate to each market.
- Add frequency caps and sponsored labels for user trust.
- Use remote configuration for ad placement and experiments.
- Track revenue/CTR separately from organic content analytics.

The current build deliberately uses Google-provided test IDs.
