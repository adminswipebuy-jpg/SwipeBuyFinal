# SwipeBuy V7.5 — Seller Commerce Pro

Adds a unified merchant workspace for storefront customization, products, orders, customer relationships and growth tools.

## Product direction
- Storefront identity and featured collections
- Product creation and inventory handoff
- Order visibility
- Customer relationship foundation
- Discounts and promotions hooks
- Delivery/pickup controls
- Reviews and seller reputation
- Growth links into analytics, ads, wallet and AI

## Production notes
- Seller data must be authorized server-side; client UI is not a trust boundary.
- Pricing, inventory, order status, refunds and payouts should be validated by trusted backend functions.
- The current release provides the UI/domain foundation; compile and device-test in a Flutter SDK environment.
