# SwipeBuy V5.3 — Search & Discovery 2.0

V5.3 introduces a unified search experience across SwipeBuy's multi-vertical ecosystem.

- Universal search across products/listings, jobs, news, sports, finance, property, people and categories.
- Search filters for All, People, Businesses, Products, Jobs, News, Sports, Finance and Property.
- Trending search shortcuts for common discovery journeys.
- Tappable results route into existing listing, professional and category experiences.
- Architecture is intentionally lightweight at this stage; production full-text search should move to a managed index (e.g. Algolia, Typesense, OpenSearch) once the dataset requires it.
