# SwipeBuy V3.5 — Alerts, Transfers & Staff Workflows

## Added
- Inventory transfer request foundation.
- Source/destination location model.
- Transfer status tracking.
- Low-stock alert acknowledgement model.
- Inventory workflow page.
- Low-stock UI foundation.
- Staff/workflow architecture notes.

## Production requirements
- Transfers must be executed transactionally by trusted backend functions.
- Source stock must be reserved/decremented and destination stock incremented atomically.
- Only authorized merchant staff can request/approve/complete transfers.
- Add staff roles such as owner, manager, inventory staff and fulfillment staff.
- Low-stock alerts should be generated by backend triggers and delivered through push/email/in-app notifications.
- Do not allow clients to create fake stock movements or acknowledge alerts without authorization.
- Add transfer audit trail, timestamps, actor IDs and idempotency keys.
- Add reorder points, preferred suppliers and automated purchase-order workflows.
- The current low-stock screen is a UI placeholder and does not claim live alert data.
