# SwipeBuy V6.6 — Content Creation Studio

Adds a production-oriented creation workflow for vertical content:

- Camera or gallery video capture
- Video preview/playback
- Trim range metadata
- Caption writing
- Category selection
- Auto-caption preference
- Music/soundtrack selection metadata
- Text-overlay metadata
- Save drafts
- Publish video content

The current release stores editing metadata and uploads the source video. A future media-processing backend should perform actual server-side trimming, transcoding, captions, cover-frame extraction and optimized delivery.
