# SwipeBuy V3.3 — Inventory Automation + Bulk Management

## Added
- Inventory management service.
- Low-stock threshold and low-stock flag foundation.
- Bulk activate/deactivate actions.
- Inventory management page.
- Quick bulk catalog/product-entry page.
- SKU visibility in inventory.
- Batch writes for bulk status changes.

## Production requirements
- SKU uniqueness must be enforced transactionally on the trusted backend.
- Inventory reservations and decrements must happen server-side.
- Prevent negative inventory and concurrent overselling.
- Low-stock notifications should be generated by a backend trigger/queue, not trusted to the client.
- Add CSV/XLSX import validation, duplicate detection and rollback.
- Add audit logs for stock changes.
- Track inventory movements (sale, restock, cancellation, return, adjustment).
- Add warehouse/location inventory for merchants with multiple locations.
- Client-side bulk controls are convenience UI only; authorization remains backend-controlled.
