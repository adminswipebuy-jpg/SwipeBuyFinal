# SwipeBuy V1 — Feed & Marketplace Layer

This build adds the next product layer on top of the Firebase-connected secure foundation:

- TikTok-style vertical marketplace feed using PageView
- Category filtering for Jobs, Food, Hotels, Beauty, Lifestyle, Entertainment, Education, Property, Sports and Services
- Listing cards with Buy / Book / Hire / Apply / Enroll / Get Ticket actions
- Listing details screen
- Professional staff directory and profile screen
- Create Listing form foundation
- Business/service/job listing data model foundation
- Safe client architecture: payment secrets remain server-side

Important:
- The demo feed uses UI artwork/gradients rather than bundled production videos.
- Real video upload/playback, moderation, payment checkout, maps, chat, notifications and server-side order/payment verification remain integration stages.
- Firebase rules/security files from the previous build are preserved.
