# SwipeBuy V4.0 — Content & Opportunity Ecosystem

This release extends the existing marketplace foundation into a broader discovery platform.

## Added verticals
- News
- Forex
- Crypto
- Investment
- Real Estate
- Fitness
- Travel

## UX additions
- Explore SwipeBuy category grid
- Category-specific vertical swipe hubs
- Personalized-feed-ready category model
- Category-specific calls to action
- Explore entry from the Home header
- Notifications entry from the Home header

## Architecture direction
All verticals reuse the existing Listing/feed model so future backend content providers can populate the same discovery experience without rebuilding the navigation shell.

## Next engineering targets
1. Real content ingestion for news/sports/finance.
2. Rich media cards and video playback.
3. Personalization signals and recommendation ranking.
4. Search across all verticals.
5. Moderation, rights/licensing, and source attribution for third-party content.
6. Production analytics and feature flags.
