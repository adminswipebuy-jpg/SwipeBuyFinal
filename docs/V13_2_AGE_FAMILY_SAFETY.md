# SwipeBuy V13.2 — Age Assurance, Teen Safety & Family Protection 2.0

Adds a backend-first safety layer for age-aware experiences:

- Age assurance status display and review requests.
- Safer-content preference controls.
- Discoverability and unsolicited-message protection preferences.
- Family-safety connection request workflow.
- Backend-owned age classification, eligibility, consent, account linking and enforcement.

Client code does not make age or safety decisions. It only records authenticated requests/preferences for trusted backend services.
