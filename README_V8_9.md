# SwipeBuy V8.9 — AI Recommendations & Personalization 3.0

Adds a cross-vertical For You Hub that ranks published marketplace listings, jobs, properties, professionals/services, and content using existing profile interests, preferred category/location, ratings, saves, views, and lightweight behavioral signals.

## Included
- Cross-vertical personalized sections
- For You Hub page with horizontal discovery rails
- Recommendation open-event logging
- Existing personalization and recommendation services remain available
- Version 8.9.0+65

## Production note
This is an application-layer personalization foundation. A production-scale system should move ranking to trusted backend services, add proper feature stores/embeddings, experiment safely, and enforce privacy, security, and regional data policies.
