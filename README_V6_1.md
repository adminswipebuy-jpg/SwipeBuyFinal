# SwipeBuy V6.1 - Super-App Home 2.0

V6.1 refreshes the main home experience around a premium, unified discovery dashboard.

## Included
- Faster access to Ask SwipeBuy, Nearby, Global Map, Stories, LIVE and Wallet.
- Cleaner top navigation with Search and Notifications.
- More categories visible through horizontal navigation.
- Personalized category order remains connected to the existing personalization service.
- Hero statement reinforces the core SwipeBuy promise: discover, act and stay in one app.

## Notes
Flutter SDK compilation was not available in the build environment; run `flutter pub get` and `flutter analyze` before release.
