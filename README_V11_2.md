# SwipeBuy V11.2 — Creator Events, Ticketing & Fan Commerce 2.0

Adds a creator-event commerce control plane: published event discovery, ticket request flow, personal ticket feed, and fan-commerce entry points for merch, bundles, and limited drops.

Important: payment authorization, ticket issuance, inventory, entitlement checks, refunds, fraud controls, and fulfillment must be enforced by trusted backend services. The client only creates requests.
