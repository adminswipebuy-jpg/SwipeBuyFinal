# SwipeBuy V12.4 — Global Trust, Verification, KYC & Business Identity 2.0

This milestone adds a user-facing identity verification workflow foundation for personal, professional and business trust signals.

## Included
- Identity Verification screen
- Personal / company / organization identity types
- Business and Professional verification flags
- Backend-review status model
- Recheck request flow
- Privacy and sensitive-data handling guidance
- Profile integration

## Production notes
- Client never declares a user verified on its own.
- Real KYC/identity checks, document storage, watchlist screening and badge eligibility must run through protected backend/provider workflows.
- Sensitive evidence should not be stored in ordinary client-readable collections.
