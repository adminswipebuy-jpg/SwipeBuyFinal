# SwipeBuy V11.3 — Global Creator Marketplace, Digital Products & Fan Downloads 2.0

Adds a digital product marketplace control plane: published product discovery, buyer purchase requests, verified personal library, secure download requests, and creator publish-review workflows for courses, templates, ebooks, presets, guides and other digital resources.

Important: payment authorization, file hosting, malware scanning, license enforcement, entitlement checks, download URLs, refunds, copyright enforcement, and access revocation must be enforced by trusted backend services. The client only creates requests.
