# SwipeBuy V12.8 — Privacy Center 2.0

Adds user-facing privacy controls and backend-managed privacy requests.

Features:
- Optional personalized recommendation control
- Optional personalized ads control
- Optional analytics sharing control
- Data export request
- Privacy review request
- Protected account deletion request
- Backend-enforced transparency architecture

Important: client-side controls are preferences only. Production retention, consent, regional compliance, export/deletion execution and audit logging must be enforced by trusted backend systems.
