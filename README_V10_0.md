# SwipeBuy V10.0 — Global AI Agent Platform 1.0

V10.0 unifies the AI agent experience into one platform surface.

## Added
- Global AI Agent Platform workspace
- Installed agent view
- Published agent view
- Marketplace and Trust & Safety entry points
- Creator earnings summary
- Platform safety principles and confirmation guardrails
- User-scoped agent usage events

## Architecture note
This is a platform/control-plane milestone. Production agent execution, payment settlement, ratings enforcement, and other sensitive operations must remain backend-controlled and verified.
