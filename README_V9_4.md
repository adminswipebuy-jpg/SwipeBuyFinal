# SwipeBuy V9.4 — AI Learning & Adaptive Personalization 2.0

Adds a user-scoped learning signal layer for adaptive recommendations.

## Included
- AI learning signals per user in `users/{uid}/ai_learning_signals`
- Weighted interaction types: view, like, save, follow, book, purchase, not_interested
- Adaptive category profile summary
- New AI Learning & Personalization screen
- Profile entry point
- Production note: ranking/execution should remain server-controlled; client signals are not proof of completed transactions.

Version: `9.4.0+70`
