# SwipeBuy V8.4 — Personalized For You Feed 2.0

V8.4 improves the core social discovery loop with a lightweight feed-mode system:

- For You: uses the existing personalization preferences and engagement-aware ranking foundation.
- Trending: prioritizes high-engagement content with freshness.
- Fresh: prioritizes recently published content while retaining a quality/engagement signal.
- The mode selector appears directly above the vertical feed when the selected category is **For You**.
- Ranking remains backend-ready: production scale should move heavy ranking and event aggregation to trusted server-side jobs.
