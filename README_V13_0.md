# SwipeBuy V13.0 — Global Platform Governance, Moderation & Safety 1.0

Adds a platform-wide governance control plane for moderation reports and appeals, with backend-first enforcement architecture.

Includes:
- Moderation reports for content, accounts, sellers, professionals and AI agents
- Appeal request workflow
- Governance & Safety center
- Backend/admin enforcement boundary
- Profile integration

Important: client requests do not decide moderation outcomes or account enforcement. Production enforcement, audit logs, and policy decisions must run in trusted backend/admin infrastructure.
