# SwipeBuy V10.1 — Global Payments, Wallet & Checkout 3.0

Adds a unified global payments preference center on top of the existing checkout and wallet foundations.

## Included
- Country and currency preferences
- Default payment method preference
- Global Payments page linked from Profile
- SwipeBuy Wallet handoff
- Backend/provider-first payment safety boundary
- No client-side payment confirmation or credential storage

## Production boundary
This milestone stores payment preferences. Actual card/mobile-money/bank authorization, FX conversion, settlement and final order/payment status must be handled by trusted payment providers and backend services.
