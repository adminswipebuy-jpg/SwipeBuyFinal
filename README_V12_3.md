# SwipeBuy V12.3 — Professional Payments, Escrow & Disputes 2.0

Adds a buyer-side financial workflow foundation for professional services: escrow funding requests, payout-release requests and dispute creation. The Flutter client only creates requests; trusted backend/payment providers must validate balances, milestones, releases, refunds, disputes, fraud checks, KYC/AML and all final payment state.
