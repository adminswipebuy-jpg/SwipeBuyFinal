# SwipeBuy V13.3 — Child/Teen Wellbeing, Screen-Time & Safer Recommendations 2.0

Adds a preference layer for wellbeing-oriented experiences:

- Optional take-a-break reminders.
- Safer recommendation preference.
- Quiet/non-essential notification preference.
- Reduced social-pressure signals preference.
- Authenticated wellbeing events and review requests.
- Backend-owned recommendation eligibility, age safety, enforcement and policy decisions.

Client code only stores authenticated preferences and requests; it does not make age, medical or safety determinations.
