# SwipeBuy V13.12 — Global Localization, Language & Regional Experience 2.0

Final major V13 feature milestone.

## Added
- Language preference foundation
- Country and regional preference controls
- Display-currency preference
- 12/24-hour time preference
- Metric/imperial-ready measurement preference
- Localization service for app-wide integration
- Translation-ready UI architecture
- Regional preference screen

## Production boundaries
Currency display preferences are not authoritative FX conversion or settlement. Taxes, legal eligibility, localized policy enforcement, payment settlement and regulated data handling must remain backend/provider controlled.
