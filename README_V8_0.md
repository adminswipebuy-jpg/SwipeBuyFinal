# SwipeBuy V8.0

## Notifications & Personal Connections 2.0

This milestone strengthens the social layer with a dedicated Connections center, follow/unfollow controls, user discovery, profile notification entry points, and notification settings access.

### Notes
- Firestore remains the source of truth for follows and notifications.
- Authentication is required for personalized connection data.
- Production should add server-side pagination, indexes, abuse limits, and privacy-aware user discovery before large-scale launch.
